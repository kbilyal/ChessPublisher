# Chess-Publisher Windows Fluidity Preview

Portable Windows UI preview for Chess-Publisher v1.06.00-beta.34.

## v2 goals

- Keep the Pairings Result Desk fixed while only the board table scrolls.
- Keep the Chess-Results tab visible in the top navigation.
- Reduce UI fragmentation and unnecessary visual work.
- Keep an F8 A/B switch between Fluidity ON and the original UI behavior.
- Do not change pairing, TRF, Gacrux, BBP, Tie-Break, or Chess-Results protocol/core logic.

The preview package is generated from the protected beta.34 UI and is intended for Windows responsiveness testing only.
